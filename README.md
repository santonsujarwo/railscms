# RailsCMS

A custom Ruby on Rails CMS built around ACF-inspired Hybrid Flexible Content.

## Architecture

- Ruby on Rails server-rendered public website
- Rails admin with Hotwire and Stimulus
- PostgreSQL with JSONB flexible content
- Developer-defined section registry with administrator-configurable fields
- Global design tokens and responsive section settings
- Railway deployment with Docker

## Current status

Project foundation is being prepared. Visual drag-and-drop page builder is intentionally out of scope for v1.
